# 月记

[打开应用](https://blackdandy-art.github.io/yueji-pwa/)

独立实现的经期与每日感受记录 PWA。支持 Mac、iPhone 和 iPad。

记录默认保存在当前设备、当前浏览器和当前网址。用户主动开启后，自动将端到端加密备份保存到维护者的 MacBook，每个用户有独立 ID 和目录，维护者不持有解密密钥。Mac 需开机联网、保持服务可达；离线时先保存在本机，重新连通后补传。恢复文件用于找回原 ID 并解密，不会自动合并不同设备的记录。请另行保管 JSON 备份与恢复文件。

iPhone / iPad 使用 Safari 分享 → 添加到主屏幕；如出现“作为网页 App 打开”，保持开启。Mac Safari 可选择文件 → 添加到程序坞。安装后从新图标联网打开一次，加载离线资源。

预计日期仅供参考，不用于诊断或避孕。
