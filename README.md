# 月记

[打开应用](https://blackdandy-art.github.io/yueji-pwa/)

独立实现的经期与每日感受记录 PWA。支持 Mac、iPhone 和 iPad。

记录只保存在当前设备、当前浏览器和当前应用网址的本地存储中，无服务器数据库和自动同步。更换设备或网址时，请通过设置中的 JSON 备份手动迁移。

iPhone / iPad 使用 Safari 分享 → 添加到主屏幕；如出现“作为网页 App 打开”，保持开启。Mac Safari 可选择文件 → 添加到程序坞。安装后从新图标联网打开一次，加载离线资源。

预计日期仅供参考，不用于诊断或避孕。
