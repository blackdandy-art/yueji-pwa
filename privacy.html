隐私政策

更新日期：2026 年 10 月 13 日。适用于月记网页应用及月记原生版 1.0。月记是独立的个人周期记录工具，与美柚无关联。

记录与保存

经期、房事、心情、症状、体温、体重、饮食、睡眠、便便、日记、照片及计划仅在当前设备处理和保存。月记没有用户账号、服务器数据库、广告、分析统计或追踪 SDK，不将这些记录发送给开发者或第三方。

网页应用将记录保存在当前浏览器、当前网址的本地存储中；原生应用将记录保存在应用本地目录，并将记录目录排除在系统云备份之外。两者均不提供自动同步。删除应用、清理浏览器数据或更换设备可能丢失记录，请先自行导出备份。

照片、文件和设备认证

只有你主动选择的照片或文件会被读取。原生版将选中的照片缩小并重新编码，移除原有图片元数据后存入本地记录。文件导入会先校验并显示数量，确认后替换当前记录。设备认证由 Apple 系统处理，月记不读取或保存你的指纹、面容信息或设备密码。

提醒、导出和分享

原生版仅在你点击开启提醒时请求通知权限。提醒在本机安排，通知内容不显示个人记录。JSON 备份包含个人记录及照片；你导出、分享或将文件保存到云盘后，其去向由你选择的系统服务或接收方处理。关爱卡只分享你确认的文字。导出日历包含所选计划或预计经期，请自行选择保存位置。

健康反馈

心情、症状、经期与睡眠反馈（含同日症状组合的可能原因）由本机规则匹配，在当前设备计算，不调用远程AI或分析服务，不分析日记正文或照片。只有你主动打开健康来源链接时，浏览器才会访问相应资料网站；周期记录不会附在链接请求中。

网页访问

应用核心无需网络服务。打开本帮助或隐私网页、网页应用首次加载或检查更新时，浏览器会向 GitHub Pages 请求静态文件。托管服务可能处理 IP 地址及访问日志，详见 GitHub 隐私声明。月记不会将你的周期记录附在这些请求中。

你的控制

你可以修改或删除单次经期、某天的记录、照片和计划；在设置中导出、导入或清空全部记录，关闭提醒和设备认证锁。月记没有服务器账号，因此无需注销账号。公开反馈时请勿提交健康记录、备份、设备密码或其他私人信息。

用途与联系

预计日期仅供参考，不能用于诊断或避孕。开发与维护账号为 GitHub 的 blackdandy-art。隐私问题及功能反馈可通过 项目反馈页 提交；该页面的内容公开可见，请仅描述问题，不附个人记录。原生版正式发布前，将补充实际发布主体与私人联系渠道。
