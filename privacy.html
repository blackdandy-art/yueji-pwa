隐私政策

更新日期：2026 年 10 月 17 日。适用于月记网页应用及月记原生版 1.0。月记是独立的个人周期记录工具，与美柚无关联。

记录与保存

经期、房事、心情、症状、体温、体重、饮食、睡眠、便便、日记、照片及计划默认在当前设备处理和保存。没有广告、分析统计或追踪 SDK。未配置 Mac 备份服务或未由你主动开启时，不上传记录。

网页应用将记录保存在当前浏览器、当前网址的本地存储中；原生应用将记录保存在应用本地目录，并将记录目录排除在系统云备份之外。原生版仍不提供云备份。网页版可在Mac 服务接入后，由你主动开启下述加密备份。删除应用、清理浏览器数据或更换设备可能影响记录、匿名身份及设备密钥，请先自行导出备份并保管恢复文件。

可选 Mac 加密备份

启用前会显示 Mac 服务地址、备份范围并征求同意。无需邮箱或手机号注册；本设备生成独立用户 ID 和随机身份凭据。完整记录先在本设备使用 AES-256-GCM 加密，再保存到维护者 MacBook 的独立用户目录；不使用第三方云存储数据库。维护者不接收你的解密密钥；Mac 只保存身份凭据的哈希、用户 ID、时间、文件大小和密文。服务端按身份隔离用户。本次内测使用 Tunnelmole 临时 HTTPS 网络转发入口。转发服务会处理连接 IP、请求和加密备份传输，可能保留服务日志；它不接收解密密钥，月记不将其作为云存储数据库。备份文件由 Mac 服务保存。

恢复文件 v2 包含解密密钥、用户 ID、Mac 服务 ID 和身份凭据，只由你下载保管；你同意后，本设备另行保管不可导出的加密密钥用于自动备份。恢复密钥丢失且本机明文已丢失时，维护者无法解密恢复。清理数据或换设备后，可用原恢复文件 v2 找回同一 ID 并在本机解密。仅有用户 ID 不足以访问备份。请勿分享恢复文件。

备份仅在网页运行且条件具备时自动上传；关闭网页期间无法保证继续上传。Mac 关机、睡眠、合盖进入睡眠、断网或服务不可达期间无法接收备份；手机先保留本地记录。联网或重新打开后检查版本并补传；版本冲突停止自动覆盖。内部测试期间保留已提交的历史密文版本，暂不自动到期清理。可在设置停止后续备份；清空本机记录不删除已经保存的 Mac 备份。退出测试或请求删除这些副本时，请联系维护者，并只提供用户 ID，不提供恢复密钥。删除未完成前不能视为已清除远端副本。

照片、文件和设备认证

只有你主动选择的照片或文件会被读取。原生版将选中的照片缩小并重新编码，移除原有图片元数据后存入本地记录。文件导入会先校验并显示数量，确认后替换当前记录。设备认证由 Apple 系统处理，月记不读取或保存你的指纹、面容信息或设备密码。

提醒、导出和分享

原生版仅在你点击开启提醒时请求通知权限。提醒在本机安排，通知内容不显示个人记录。JSON 备份包含个人记录及照片；你导出、分享或将文件保存到云盘后，其去向由你选择的系统服务或接收方处理。关爱卡只分享你确认的文字。导出日历包含所选计划或预计经期，请自行选择保存位置。

健康反馈

心情、症状、经期与睡眠反馈（含同日症状组合的可能原因）由本机规则匹配，在当前设备计算，不调用远程AI或分析服务，不分析日记正文或照片。只有你主动打开健康来源链接时，浏览器才会访问相应资料网站；周期记录不会附在链接请求中。

网页访问

应用核心无需网络服务。打开本帮助或隐私网页、网页应用首次加载或检查更新时，浏览器会向 GitHub Pages 请求静态文件。托管服务可能处理 IP 地址及访问日志，详见 GitHub 隐私声明。月记不会将你的周期记录附在这些请求中。

你的控制

你可以修改或删除单次经期、某天的记录、照片和计划；在设置中导出、导入或清空全部记录，关闭提醒和设备认证锁。如已开启Mac 加密备份，可停止备份并通过用户 ID 请求删除Mac 上的用户身份及相关密文备份。公开反馈时请勿提交健康记录、备份、设备密码或其他私人信息。

用途与联系

预计日期仅供参考，不能用于诊断或避孕。开发与维护账号为 GitHub 的 blackdandy-art。隐私问题及功能反馈可通过 项目反馈页 提交；该页面的内容公开可见，请仅描述问题，不附个人记录。原生版正式发布前，将补充实际发布主体与私人联系渠道。
